I'm Antonio, a QA Engineer based in Recife, Brazil, moving into DevOps and Infrastructure with hands on production experience in **Kubernetes, Docker, ArgoCD (GitOps), AWS, CI/CD, and Terraform/OpenTofu**. I like understanding why something happened before I trust the result, and that habit is what led me to diagnose production incidents on my own, from root cause all the way to the post mortem, and to build a CI/CD pipeline with ephemeral test environments from scratch.

AI is part of how I work, not just a topic I follow. I use **Claude Code** daily to investigate problems and write automation, and that's how I've been learning most of DevOps in practice. I'm also a **Claude Certified Architect (Foundations)**.

I care a lot about open source and I'm always happy to help if you have a question or just want to talk shop.
